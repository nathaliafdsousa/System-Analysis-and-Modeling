# Plataforma de Simulação e Cálculo de Milhas ✈️
---
## 📌 Sobre o Projeto
### Este repositório contêm a documentação do projeto **Plataforma de Simulaçao e Cálculo de Milhas**, desenvolvido como parte da disciplina de Análise e Modelagem de Sistemas.
#### O objetivo é criar uma solução capaz de simular a quantidade de milhas necessárias para emissão de uma passagem áerea e calcular quantas milhas faltam para atingir a meta,considerando diferentes programas de fidelidade,regras de acúmulo e cenários de compras.
